# Standard Works Dataset

The data contained in this dataset as structured in JSON and obtained from various public domain sources.

## Contents

Out of respect to the intellectual property, all chapter headings, summaries, annotations, footnotes, title pages, etc., have been intentionally omitted from this dataset.

- `scriptures/source/book-of-mormon.json`:
  - volume, chapter, and verses only
- `scriptures/source/doctrine-and-covenants.json`:
  - section and verses only
- `scriptures/source/pearl-of-great-price.json`:
  - volume, chapter, and verses only
- `scriptures/source/old-testament.json`:
  - volume, chapter, and verses only
- `scriptures/source/new-testament.json`:
  - volume, chapter, and verses only
